#虚幻引擎界面基础操作

#1. 菜单栏

#文件

#功能

提供新建关卡、打开关卡等选项

#关卡概念

  • 当前视口中看到的场景就是一个关卡
  • 类似于游戏中的"地图"（如 CSGO 中的炙热沙城、炼狱小镇）
  • 关卡 ≈ 游戏内的地图

#编辑

  • 这个二级菜单的上方按钮基本用不到，因为基本都是使用快捷键
  • 下方存在编辑器偏好设置、键盘快捷键、项目设置和插件

#窗口

  • 改变布局的入口
  • 可以添加、删除以及把误删的一些界面改回来

#工具

  • 优化游戏性能的入口

#构建

  • 可以用于优化场景性能
  • 在开发过程中所有设置选项保持默认即可，设置高了会导致卡顿

#平台

  • 用于游戏打包、上线或者发给外部人员游玩时，打包成可运行文件的入口

#选择

  • 用于选择场景内物体的入口
  • 可进行全选、反向全选，以及分类全选
  • 一般情况下用的比较少

#Actor

#功能

用于编辑选中的物体

#界面状态

  • 图一：未选中物体时的空白界面
  • 图二：选中物体时的界面
  • 选中方式：
    • 单击界面内物体
    • 直接点击右侧大纲界面内的条目（大纲包含界面内所有物体）

#注意点

选中大纲内分组时因为未选中具体物体，Actor 界面显示为图一的空白状态

#帮助

各类网页链接入口，学习笔记中的自助答疑方法中已经详细说明

#2. 标签页

  • 和浏览器标签页同理，可以进行窗口的标签页合并以及标签页的窗口化独立分割
  • 注意：鼠标中键可以快速关闭当前标签，因此也需要注意不要误触

#3. 主工具栏

在日常开发虚幻引擎游戏中使用最多的功能：

#第一个按钮 - 保存

快捷键 Ctrl+S

#第二个按钮 - 浏览相关关卡

默认跳转到你上一个操作的位置。

举例：如果上一个双击打开了文件，点击定位到那个文件；如果上一个是点击了某个关卡，点击跳转到关卡文件

#第三个按钮 - 模式

点击切换不同模式，默认选择模式，快捷键为 Shift+数字键。

切换到地形模式后可以对界面内地形进行编辑

#第四个按钮 - 快速添加到项目

可以快速添加物品到项目中，也是外部资源导入项目的入口

#第五个按钮 - 蓝图

可以快速打开项目中的蓝图，使用较少

#第六个按钮 - 关卡序列

可以添加关卡序列，制作过场动画

#4. 视口工具栏

操作场景相关的内容

#前四个按钮

在学习笔记中的变换工具快捷键中已经详细说明中已有说明，第一个按钮为默认选择，即选择模式

#预设比例

  • 如下图后面三个预设比例选项分别对应上图平移、旋转、缩放的单次数值
  • 即平移的单位距离，旋转的单位角度以及缩放的单位比例
  • 将对应选项点击关闭后，不会无法平移、旋转、缩放，而是进入无极调整的状态

#摄像机速度

  • 设置在编辑模式下视角移动的速度
  • 编辑模式下的视角移动方式在学习笔记中的编辑模式下的视角移动方式中已有说明
  • 快捷键：右键+滚轮，当滚轮向上滑动时速度提高，向下滑动时速度降低

#光照

使用频率不高，主要用于检查游戏内光影效果，可以切换到不同光照效果

#5.大纲视图

场景中的所有元素都会在大纲视图中进行列举展示

#元素的重命名

  • 元素过多时，可以对元素进行重命名并在大纲视图中的搜索中进行搜索
  • 重命名的快捷键：F2

#元素在场景中的快速定位

  • 选中需要定位元素后按F键
  • 双击所选元素

视角就会立刻转到元素所在位置并且显示选中状态

#细节

  • 图一是在没有选中物体时，细节界面没有内容
  • 图二是选中物体时，细节界面内容

细节可以针对选中的物体进行数值化、精细化的操作，譬如图中可以直接填写选中物体位置、旋转、缩放的各项具体数值，或者材质、物理模拟等

当缩放文本右侧的锁点击锁上之后，缩放仅会进行等比例缩放，不能对XYZ轴进行单独调整

#世界场景设置

如果没有该设置的，可以在窗口中点击添加

用于编辑关卡相关设置

#6.底边栏

#内容侧滑菜单

  • 快捷键：Crtl+空格
  • 游戏内需要使用的所有资源、素材都会显示在其中
  • 包括模型、代码、动画等

#场景内元素快速定位

右键场景大纲内元素，选择第一项浏览至资产

#目录排布

  • 在内容侧滑菜单的路径选择中点击所有，进入根目录
  • 默认根目录下为内容和引擎

引擎目录没有的，点击内容侧滑菜单右上角齿轮图标，点击勾选引擎目录即可

在创建空白项目时，内容子目录应该为空，如果选择模板进行开发，内容子目录下有内容

引擎子目录为虚幻引擎自带的内容，一般情况下不要动，类似于Windows系统下C盘的Windows文件夹下的内容

#输出日志

  • debug最直接的方式，可以直观的从日志内找到所有需要的信息
  • 位置在底部内容侧滑菜单的右侧第一个按钮

#诊断

在优化游戏性能时可以直接参考的数据窗口

#保存内容

点击之后可以直观检查本次所有未保存的改动，并且可以点击进行保存
