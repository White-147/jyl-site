#蓝图编程基础

#1.新建游戏模板基础和角色

#新增游戏模板基础

由于蓝图基础中的第一人称关卡模板自带可移动人物等设置，为方便后续从零开始学习，新建关卡和角色

在内容侧滑菜单中的Code目录下（蓝图基础中新增目录），右键新增蓝图类-游戏模式基础，命名为BP_GameMode

双击游戏模式基础，进入相应界面

#新增角色

右键新增蓝图类-角色，创建用于编写的角色,命名为BP_Charater

  • 修改游戏模式基础的细节界面中默认Pawn类为新增的BP_Charater
  • 注意：如果误点击了别处，可以左键单击组件界面的BP_GameMode唤出细节界面
    • 修改完默认Pawn配置后，记得点击编译和保存
  • 返回之前所在的FirstPerson关卡中，将新增的游戏模式基础设置到关卡中
  • 在世界场景设置中，将游戏模式重载设置为Node或者刚刚新增的BP_GameMode
    • 注意，如果右侧默认没有世界场景设置，可以在窗口中点击添加
  • 在编辑-项目设置中的地图和模式，设置默认游戏模式为新增的BP_GameMode

#2.实现角色移动

#新增映射上下文

由于轴映射和键盘映射的输入方式已经被弃用，因此采用增强输入的方式实现复杂的输入功能

在内容侧滑菜单的Code目录下右键新增增强输入，为区分原有的移动输入命名，命名为IA_Move2

双击IA_Move2进入细节界面，修改值类型为Axis2D，因为前后左右移动为二维向量操作，修改后点击保存或Ctrl S

右键新增输入映射上下文，命名为IMC_Input

#设置映射上下文

双击IMC_Input进入细节界面，展开Default Key Mappings，在Mappings栏点击新增映射操作（+号）

展开Mappings栏，选择新增的IA_Move2输入

因为要设置WASD进行移动，所以点击四次Mappings子栏中的将一个控制绑定到映射操作（+号）

将设置好的子栏展开，在新增的四个映射栏中点击选择键值（键盘按钮），依次按键盘上的WASD，完成设置

再次展开WASD键值栏，依据平面坐标系，当角色后退（向下移动）或者向左移动时，坐标所在位置为负数

因为键盘映射操作默认为X轴，AD与WS移动不在一个轴，所以需要额外设置拌合输入轴值，将AD操作的默认轴改为Y轴

同时因为A向左移动，也要设置S同样的否定元素，因此需要新增两个元素

#激活映射上下文

点击保存或Ctrl S，返回BP_Charater，进入事件图表界面，将设置好的增强输入激活

在事件图表界面右键搜索输入get player controller，点击新增玩家控制器节点

左键长按玩家控制器右侧蓝色引脚拉出，在搜索输入框输入enhanced，获取增强输入本地玩家子系统

左键增强输入本地玩家子系统右侧蓝色引脚，在搜索输入框中输入add mapping context，获取映射上下文

左键长按事件开始运行的左侧执行引脚，连接到映射上下文

如果觉得界面拥挤，可以按del键或右键删除其他两个初始节点，目前用不到

连接之后，在映射上下文节点中的选择资产中，选择已设置的IMC_Input

#编写角色移动

在事件图表界面右键，在搜索框中输入IA Move，选择强化操作事件中的IA Move2

在新增的节点中，点击展开，左键长按Action Value右侧引脚，搜索输入break，选择拆分向量2D

Action Value为向量2D结构，拆分向量2D可以将2D向量拆分为X和Y的两个浮点数

在事件图表界面右键，在搜索框中输入add movement input，点击添加

IA Move节点中存在多个引脚，其中Triggerd引脚设置持续移动，因此需要将Triggerd引脚连接到新增的移动输入节点

因为一般游戏中角色移动的方向取决于角色当前视角正前方的方向，因此还需要新增获取Actor向前向量

右键搜索输入get actor forward，选择后左键长按右侧黄色引脚，连接到移动输入的World Direction引脚处

#实现角色移动

Scala Value数值为正时，角色朝对应方向移动，数值为负时，角色朝向反方向移动

因此需要将拆分向量2D的X数值连接到Scala Value引脚处，此时WS的向前向后移动在完成编译之后即可生效

在已有的add movement input节点的执行引脚处，长按左键新增新的add movement input

因为需要实现的是左右移动，因此不能使用向前向量，右键搜索输入get actor right，新增获取向右向量

将新增的获取向右向量节点和拆分向量2D的Y数值连接到新增的add movement input的World Direction和Scala Value引脚处，点击编译后即可实现角色的左右移动

#3.实现视角移动

#新增增强输入

在内容侧滑菜单的code目录下，新增输入操作，命名为IA_Look2

双击IA_Look2，进入细节界面，因为视角的上下左右旋转也是二维操作，所以修改值类型为Axis2D

#设置增强输入

在映射上下文IMC_Input中添加操作映射，选择新增的IA_Look2

展开选好的IA_Look2，设置映射键值为鼠标的XY 2D轴，完成设置

返回BP_Charater，将设置好的IA_Look2节点添加到事件图表中

右键搜索输入IA_Look2，选中强化操作事件中的IA_Look2

#roll、yaw、pitch知识点

载体坐标系与载体坐标系的关系是三个Euler角:yaw，pitch，roll，反应了载体相对基准面的姿态：

  • pitch是围绕Y轴旋转，也叫做俯仰角（视角上下移动）。当X轴的正半轴位于过坐标原点的水平面之上(抬头)时，俯仰角为正，否则为负。
  • yaw是围绕Z轴旋转，也叫偏航角（视角左右移动）。即机头右偏航为正，反之为负。
  • roll是围绕X轴旋转，也叫翻滚角（视角旋转）。机体向右滚为正，反之为负。

#新增yaw、pitch

视角移动也属于持续操作，左键长按Triggerd的执行引脚，在搜索输入add yaw，选择添加控制器Yaw输入

右键搜索输入add pitch，选择添加控制器Pitch输入

左键长按IA_Look2节点的Action Value的引脚

快捷操作：将弹出的界面下滑到最底部，直接选择拆分向量2D，或直接右键Action Value文本，选择分割结构体引脚，Action Value会分裂成Action Value X和Action Value Y

#编写视角移动

连接yaw输入和pitch输入的执行引脚

因为yaw负责左右视角移动，pitch负责上下视角移动，所以将2D向量的X连接到控制器Yaw输入的Val输入引脚，将2D向量的Y连接到控制器Pitch输入的Val输入引脚

#实现视角移动

点击编译后测试，会发现左右视角移动正常，但是上下视角移动颠倒

解决方案有两个：

1.将y轴输入值取反：

  • 在事件图表界面右键搜索输入*，选择运算符乘
  • 将左上方引脚连接到向量2D的Y引脚，左上角连接到控制器Pitch输入的Val输入引脚
  • 在添加引脚的左侧输入框内修改数值为-1.0

2.在映射上下文IMC_Input中继续修改IA_Look2：

  • 展开IA_Look2的选择键值栏，在修改器栏选择添加元素
  • 在新增的索引栏选择否定，取消XZ选项，仅保留Y的勾选
  • 注意：此方案不需要更改原有事件图表中的连接

#4.添加注释

长按鼠标左键，框选住需要注释的节点群，松开后按键盘C键

#5.实现自动门功能

#导入素材

在虚幻引擎界面已经安装Fab插件之后，在项目界面内的窗口或内容侧滑菜单界面选择Fab商城

  • 在弹出的Fab界面内的搜索框中输入wooden door，回车后在下方条件筛选栏的最后，选择更多筛选条件，之后选择价格，勾选免费
  • Fab商场全屏展开的情况下，直接选择价格筛选条件
  • 如果Fab商城长时间无法加载成功，检查网络或选择加速器和梯子

在筛选后的界面内选择如图木门资源，点击购买之后选择添加到项目

  • 出现内容浏览器，代表素材导入成功，此时可关闭Fab商城
  • 将内容浏览器显示的路径/Game/Fab/Wooden_Door进行复制，之后关闭内容浏览器
  • 打开内容侧滑菜单，将复制的路径覆盖到当前目录上，路径对应根目录下Fab目录的Wooden_Door目录
  • 目录中包含六个文件，第一个02_defalut为材质，是第二个素材Door门和第六个素材DoorFrame门框的材质，决定了门的外观，后续三个Door_Door_*是纹理，类似于贴图，可以使用在第一个素材材质上面
  • 关键在于第二个素材和第六个素材静态网格体，可以理解为模型

#修改门框碰撞体

将DoorFrame门框拖拽到关卡内，在运行后移动角色穿过门框，会发现门框无法穿过

双击DoorFrame，点击右上角光照，选择玩家碰撞，之后可以发现门框中间是实心的，因此角色无法通过

选择标签页下方的碰撞选项：

  • 如果选择移除碰撞，再选择玩家碰撞模式观察，会发现在此模式中整个模型消失不见，说明整个门框都取消了碰撞体积
  • 如果选择自动凸包碰撞，引擎会自动识别光照模式下可视模型范围，将对应模型转换为碰撞体
    • 选择自动凸包碰撞后，右下角会出现凸包分解窗口，如果在玩家碰撞模式下观察感觉碰撞体存在瑕疵，与观察模型相差较大，可以通过增加凸包数量、凸包精准度，来增加精确度
    • 增加对应设置之后会增加游戏负荷，不利于游戏优化，需要进行取舍

选择自动凸包碰撞，在凸包分解窗口选择应用之后，返回关卡FirstPerson标签，点击运行，可以发现此时门框内部角色可以穿过，但门框本体角色无法穿过

#修改门框体积

目前门框在关卡内体积过大，在关卡场景或大纲窗口中左键单击DoorFrame之后，选择右下角细节窗口，在缩放一栏点击锁定，之后在XYZ任意一个输入框中输入0.48

#绑定门与门框

将门Door素材拖拽到关卡界面内，会发现门和门框都为静态资源，无法实现人物接近之后开关门的效果，因此需要将门和门框都放进蓝图内，作为编写蓝图类代码的一个资源

删除关卡界面内的门和门框，打开内容侧滑菜单，在code目录下新建蓝图类-Actor，命名为BP_Door

在内容侧滑菜单code目录下，左键双击新建的BP_Door，进入BP_Door的视口界面

左键单击组件窗口下方的新建两次，选择静态网格体组件，一个命名为Door，一个命名为DoorFrame

可以观察到此时DoorFrame在Door分级下，此时DoorFrame为Door的子类，目前用不到父子类关系，因此可以左键长按DoorFrame拖动到Door栏，松开后DoorFrame与Door平级

左键单击Door或DoorFrame，在右侧细节窗口出现内容，在静态网格体栏中选择绑定已有的Door或者DoorFrame资源

在变换栏中的缩放为锁定状态下，在后续任意栏中输入0.48，调整两个模型的体积大小

在Actor视口界面，手动调整门与门框的位置，可以在视口菜单的移动对齐数值设置按钮处设置移动模型的单位距离，闭关时为无极调整

可以在透视右侧的按钮处调整视角移动的速度，或者右键的同时移动滚轮来调整

#编写单向自动门

为了实现在人物接近时门自动开关，需要进行碰撞检测，因此还需要在BP_Door中加入Box Collision，在视口界面的组件页下方左键单击添加，搜索选择Box Collision

  • 如图，盒型碰撞实际为一个方形，当角色或模型进入方形范围内就会发生某种响应，触发一些逻辑，因此需要将方形范围覆盖整个门
  • 选中组件窗口中新增的盒型碰撞Box，在细节窗口的形状页中，调整盒体范围，虽然调整缩放也可以调整盒体范围，但准标做法就是调整盒体范围的数值
  • 注意：可以将鼠标放置在数值上，鼠标光标显示为左右箭头时，左键长按往左右拉动，往右为数值调大，往左为数值调小

将盒型碰撞Box的细节页滑动到最底部，点击组件开始重叠时的右侧加号以及组件结束重叠时的右侧加号

跳转到Box的事件图表，在事件图表中会新增组件开始重叠时和组件结束重叠时的节点，代表只要有模型进入和离开盒体范围，就会执行节点后续代码

先将组件结束重叠时的节点移到一旁，在组件开始重叠时的节点右侧右键搜索输入time line，点击添加最底部的添加时间轴，命名为MyDoor

时间轴节点的主要作用是为了实现数值的线性增长与减小，而门的开与关，可以视为门沿z轴旋转，即关门状态代表z轴旋转0度，关门状态代表z轴旋转±90度（视实际情况为准）

打开BP_Door的事件图表界面，左键双击新建的时间轴MyDoor节点，在进入的详情界面内左键单击+轨道

  • 在新建的轨道界面内右键单击新建关键帧两次，在第一个时间输入框内输入0，对应值也为0，第二个时间输入框内输入1，对应值为-90，代表从0s到1s时间内，数值从0到-90线性减少，同时修改轨道右侧长度输入框内数值为1，对应关键帧的总时间长度
  • 输入之后默认会跳转到无法完整观察到两个关键帧的部分，键盘F键或左键单击轨道界面左上角缩放进行水平和垂直匹配两个按键，就可以快速定位到已有的关键帧的部分
  • 鼠标左键单击首尾帧任意一个点，即可对对应关键帧进行编辑
  • 注意：在输入时间和值之后，需要按键盘上的enter键，将已输入的数进行保存，不可直接将鼠标点击到别处，不按enter，如果不按，输入的数将无法保存到对应输入框中
  • 返回BP_Door的事件图表界面，在时间轴MyDoor节点旁右键搜索set rotation，选择Set Relative Rotation(Door)，设置相对旋转（Door）
  • 其他设置相对旋转与左侧组件内资产一一对应，新增的节点区别仅在初始连接的节点不同
  • 如果选错了，可以将初始连接的左侧节点删除，从组件处左键拖动对应节点到事件图表内，将右侧引脚左键长按连接到Set Relative Rotation节点的目标引脚；或者直接将组件处左键拖动对应节点到Set Relative Rotation节点的目标引脚，可以直接连接

将时间轴MyDoor节点的update引脚左键长按连接到Set Relative Rotation节点的左侧执行引脚处，因为仅需要对Z轴进行旋转，所以右键New Rotation，选择分割结构体引脚，将Z轴独立出来

  • 将时间轴MyDoor的Reverse 新建轨道0引脚左键长按连接到刚刚分割出的New Rotation Z引脚处
  • 将组件开始重叠时的执行引脚左键长按连接到时间轴MyDoor的执行引脚
  • 将组件结束重叠时的执行引脚左键长按连接到时间轴MyDoor的Reverse引脚，代表相反执行，会从时间轴的1s逆向执行到0s
  • 左键单击左上角编译和保存，返回关卡界面，将BP_Door左键长按拖动到关卡界面内，单击运行或Alt P，检查运行效果

#编写双向自动门

单向门自动开合会存在角色反向进门会被开合的门模型卡住等问题，因此可以编写双向穿过门时，门都向外开关的双向自动门

首先，需要在BP_Door的视口界面额外再添加一个盒体碰撞，命名为Box2，为了区分，可以将原来的盒体碰撞重命名（按F2或右键）为Box1

如图，可以将门的旋转角度设置为±90度，将两个碰撞体的位置设置在门开关的模型之外，因为本教程设置门是向角色反方向开关，如果碰撞体在门旋转±90度模型以内，会出现时间轴被打断，门开关抽搐的情况

双击事件图表中的时间轴MyDoor节点，进入MyDoor_Template，如图，继续新增一条轨道，在新增的轨道中新增两个关键帧，分别为时间0，值0，时间1，值90（与第一条轨道值相反）

返回事件图表界面：

  • 在组件窗口左键单击新增的Box2，在右侧细节窗口底部选择组件开始重叠时和组件结束重叠时
  • 右键搜索输入time line，新增时间轴，右侧右键搜索输入set rotation，新增Set Relative Rotation(Door)，右键New Rotation项，选择分割结构体引脚
  • 将Box2的组件开始重叠时的执行引脚连接到新增的时间轴左侧执行引脚，将Box2的组件结束重叠时的执行引脚连接到新增的时间轴左侧Reverse引脚
  • 将新增的时间轴右侧update引脚连接到新增的Set Relative Rotation(Door)的左侧执行引脚，将新增的时间轴的新增轨道连接到Set Relative Rotation(Door)的New Rotation Z
  • 点击左上角编译和保存后，返回关卡界面，单击运行或者Alt P，检查运行结果，如果觉得开门触发的太早，可以进入BP_Door的视口界面，调整Box1和Box2盒体范围的Y数值

#时间轴引脚知识补充

  • Play：顺序播放时间轴设定的关键帧对应的数值，如果时间轴播放未完成，继续播放会延续上次未完成的时间轴继续播放
    • 举例：角色走到盒体碰撞范围时，门会从当前角度线性过渡到±90度之间，表现为门丝滑打开
  • Play from Start：顺序播放时间轴设定的关键帧对应的数值，如果时间轴播放未完成，继续播放从头开始播放
    • 举例：角色每次进入盒体碰撞范围时，门会闪现到完全关闭的状态再次打开
  • Stop：不管时间轴进行到哪里，立即停止
    • 举例：如果将组件结束重叠时，也就是角色离开碰撞范围连接到Stop，表现为角色远离门后，门不继续关闭，并且后续门不会执行关闭，只会继续打开
  • Reverse：倒序播放时间轴设定的关键帧对应的数值，如果时间轴播放未完成，继续播放会延续上次未完成的时间轴继续倒序播放
    • 举例：角色离开盒体碰撞范围时，门会从已打开的角度倒序过渡到0度，表现为门丝滑关闭
  • Reverse from End：倒序播放时间轴设定的关键帧对应的数值，如果时间轴播放未完成，继续播放从最后开始播放
    • 举例：角色每次离开盒体碰撞范围时，门会闪现到完全开门的状态再次关闭
  • Set New Time：设定时间轴上一个指定的播放时间，联动下方的New Time数值
