摘 要 / Abstract

摘 要: 为了提高图书馆系统的用户体验，本文对基于用户行为的推荐算法进行研究，实现了基于Spark计算框架的实时图书推荐系统，在使用给予物品的协同过滤推荐时应用皮尔逊相关系数来衡量两者的相似度。在系统实现上，MySQL被用于部署特征库，Hive被用于存储大数据推荐信息，Spark Steaming批处理引擎被用于实现定期的推荐数据更新。前端采用Vue.js和Element框架搭建，后端通过Spring Boot读取和处理MySQL保存的数据，采用Spring Security设置拦截器，确保数据的安全性，使用Axios实现前后端的数据传输，使用Selenium完成网络爬虫获取数据缺失部分。

关键词:图书推荐，Spark，Spring Boot，Vue.js

Abstract: In order to improve the user experience of the library system, this paper investigates the recommendation algorithm based on user behavior and implements a real-time book recommendation system based on Spark computing framework, applying Pearson correlation coefficient to measure the similarity between the two when using collaborative filtering recommendations given to items. For the system implementation, MySQL is used to deploy feature libraries, Hive is used to store big data recommendation information, and Spark Steaming batch engine is used to implement regular recommendation data updates. The front-end is built with Vue.js and Element framework, the back-end reads and processes the data saved by MySQL through Spring Boot, Spring Security is used to set up interceptors to ensure the security of the data, Axios is used to realize the data transfer between the front and back-end, and Selenium is used to complete the web crawler to get the missing part of the data.

Keywords: book recommendation, spark, spring boot, vue.js

1 绪论

1.1 研究背景与意义

在科学技术不断进步的今天，数字化技术促进了全世界范围内经济的发展，它不仅可以帮助我们更好地整理、分析、利用各种要素，而且还可以极大地提升我们的生活水平，推进国家的繁荣昌盛。在全球经济衰退、新冠肺炎爆发的作用下，相对于产品和资本的全球流动受阻，新一轮数据技术相关驱动的全球数字经济仍保持持续增长，国内外大数据产业也保持着良好的发展态势，这其中也包括在线图书馆。张佳佳和章宜玉认为，随着网络技术的普及，一种全新的图书借阅管理模式应运而生，它以其卓越的便利性，大大促进了文化知识的传播，有效地提高了社会的文化素养水平[1]。

虽然网络书库给用户带来了个人借阅信息管理的便利，然而，随着行业的发展，信息过载的问题也不可避免。著名的互联网图书零售商亚马逊的平台上有7000多万册图书，在如此规模的图书面前，会造成书城的顾客因认知能力有限而降低管理决策质量，无法从中选择心仪的图书产品。基于大数据的推荐系统巧妙地解决了上述问题，马鸿健认为，基于大数据的图书推荐系统是指通过大数据算法对大量的图书进行考量，然后给所有用户提供一个专有的图书推荐代码序列的系统[2]。

1.2 大数据处理技术的发展历程

Nutch的创始人Doug Cutting受到谷歌三篇论文的启发，用了若干年时间实现了DFS和MapReduce机制。2005年，Hadoop作为Lucene子项目Nutch的一部分正式被引入Apache基金会，随后又从Nutch中剥离，成为一套完整独立的软件，起名为Hadoop，这其中主要包括Hadoop 分布式文件系统 HDFS 和大数据计算引擎 MapReduce。

Hadoop兴起后，Yahoo开发Pig试图简化MapReduce的大数据编程，Pig是一种脚本语言，使用类 SQL 的语法，经过编译后会生成 MapReduce 程序，但使用Pig依然需要学习新的脚本语法，于是Facebook为了降低大数据的开发门槛，发布了使用SQL语句的 Hive。随后，众多 Hadoop 周边产品开始出现，大数据生态体系逐渐形成。

1.3 国内外研究现状

1991年，美国首先提出了数字图书馆的概念，并且引领着其他国家的发展，他们纷纷采取行动，建立起具有针对性的个人化图书推荐系统，以满足读者的需求。

随着科技的发展，越来越多的国际高校开发出具备个性化的图书推荐服务，其中最具代表性的是康奈尔大学的MyLibrary@cornell、斯坦福大学的Fab、美国华盛顿大学的MyGateway、加利福尼亚大学的Melvyl以及联邦德国卡尔斯鲁厄学院的Big Tip，它们为读者提供更加便捷的阅读体验。

在推荐算法的采用和研究方面，斯坦福大学的Fab系统软件采用了混合协作过滤和基于内容的方法来推荐图书。以图书信息作为基础，通过共享查询频率构建出一个完整的图书推荐系统。

国内的研究和应用发展相对落后，提供个性化图书推荐服务的高校数量较少，而且这些服务的个性化水平也不够高。其中，厦门大学的My Library、中国人民大学的KingBase以及清华大学的Open BookMark都是比较知名的。
