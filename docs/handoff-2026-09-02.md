## 四、BookRecommendation 专项

- 位置：`D:\code\BookRecommendation`（Vue CLI，前端在 `frontend/`，`vue.config.js` publicPath 已支持 embedded 相对路径；本机首访慢 = **`frontend/dist`? 不，预览产物在 jyl-site `public/preview/book-recommendation/`**）。
- **根因**：chunk-vendors.js **7.72MB**（未压缩）全量单包 —— `src/main.js` 全量 `import ElementUI from "element-ui"` + `Vue.use(ElementUI)` + 全量 CSS；`plugins/element.js` 同样全量；路由全部同步 `component: Xxx`；ECharts（首页图表）大概率全量。
- **结论**：懒加载对"首次访问"无改善（页面代码本就不大），首访慢的下限=用到的库体积；且 GitHub Pages 会 gzip（实际传输约 2MB+），4G 冷访问仍有 5-10s。
- **可行优化方案（未实施，待用户确认余额）**：
  1. 路由懒加载（vue-router `component: () => import(...)`）—— 减少首包页面代码；
  2. Element UI 按需引入（babel-plugin-component + 改 `plugins/element.js`/main.js 按需注册，CSS 按需）；
  3. ECharts 按需引入（echarts/core + 仅 BarChart/LineChart/PieChart + 必要 components）。
  - 预估：vendor 7.72MB → 约 2.5–3.5MB（未压缩），gzip 后 ≈ 0.8–1MB，首访从"很久"降到可接受。
  - 改动面：`frontend/src` + `babel.config.js`；需 `cd frontend && npm run build -- --mode embedded`（vue.config publicPath 会切 ./），把 `frontend/dist` 拷贝到 `jyl-site/public/preview/book-recommendation/`（保留 img/js 结构一致），再 `node scripts/polish-previews.mjs`。
- **当前站点状态**：预览正常但冷加载慢；演示自动登录 + 数据 mock 已内置（`src/mock/mocks`）。
